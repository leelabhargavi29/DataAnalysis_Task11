Task 11 - Principal Component Analysis (PCA)

Objective:
Apply PCA on the Wine Dataset to reduce dimensionality and visualize data in 2D.

Tools Used:
- Python
- Scikit-learn
- Matplotlib

Dataset:
Wine Dataset from Scikit-learn

Steps Performed:
1. Loaded Wine Dataset
2. Standardized features
3. Applied PCA with 2 components
4. Checked explained variance ratio
5. Visualized transformed data in 2D

Output:
- Transformed Dataset
- Explained Variance Ratio
- PCA Scatter Plot
